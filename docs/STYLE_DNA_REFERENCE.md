# Style DNA من فيديو مرجعي — المواصفة (v1)

> **الفكرة:** المستخدم يكتب اسم قناة → بحث (yt-dlp) → يختار فيديو → التطبيق
> يستخرج **Style DNA** مقاسًا (إيقاع، انتقالات، أصوات، موسيقى، ألوان،
> مقدمة/نهاية) → يطبق **ما يتطلبه فيديو المستخدم فقط** عبر Matching Engine
> بقواعد ملاءمة معلنة + معاينة + toggles.
>
> **ليس** نسخ الفكرة/الإبداع (وهم)، **وليس** نسخ الأغاني المحمية (copyright).

## 1. خط الأنابيب (كله محلي — بدون AI API)

```
بحث قناة/فيديو (yt-dlp الموجود)
  → تحميل مرجعي (يُمسح بعد الاستخراج، يُحفَظ DNA فقط — كيلوبايتات)
  → تحليل إشارة متوازٍ:
      scenes      : select='gt(scene\,0.4)'  → حدود المشاهد + مددها
      transitions : حدة القطع (فرق هستوجرام) + منحنى السطوع (fade/dissolve)
      speech      : silencedetect الموجود     → كثافة الكلام
      sfx         : طاقة عابرة (onset flux)   → أحداث + مواضعها من القصّات
      music       : طبقة طاقة مستمرة + tempo  → الدور (bed/intro/outro)
      color       : histogram/color moments   → المزاج + قيم تقريبية
      bookends    : أول/آخر مقطع مقابل الجسم  → مقدمة/نهاية (heuristic)
  → StyleDNA.json (موسّع) → حفظ + معاينة بشرية
```

## 2. مخطط DNA الموسّع (JSON)

```json
{
  "version": 1,
  "source": {"channel": "...", "video_id": "...", "duration": 612.0},
  "rhythm": {"avg_shot": 2.4, "cuts_per_min": 25.0, "accelerating": false},
  "transitions": {"cut": 0.86, "dissolve": 0.10, "fade": 0.04, "wipe": 0.0},
  "sfx": {"events_per_min": 6.0, "on_cut_ratio": 0.7, "types": ["whoosh", "pop"]},
  "music": {"has_bed": true, "bed_db": -20.0, "tempo_bpm": 96.0,
            "mood": "upbeat", "has_intro_sting": true, "has_outro": true},
  "color": {"mood": "warm", "saturation": 1.15, "temperature": 6000,
            "contrast": 1.05},
  "captions": {"density": 0.9, "case": "upper", "position": "bottom",
               "words_per_caption": 3.0},
  "bookends": {"has_intro": true, "intro_sec": 3.0, "has_outro": true,
               "outro_sec": 8.0},
  "hook": {"style": "cold_open", "first_shot_sec": 1.2}
}
```

يتوافق مع `engine/src/style_dna.rs` (الحقول القديمة تُشتق من الجديد).

## 3. محرك الملاءمة (يطبق ما يتطلبه الفيديو فقط)

كل عنصر يُقيَّم بقاعدة `applies_to(فيديو المستخدم)` + سبب معلن:

| العنصر | يُطبق عندما | يُتخطى عندما |
|---|---|---|
| إيقاع القص | دائمًا (بمعامل حد أقصى 2x من الأصل) | — |
| ثيم الكابشن | يوجد كلام (transcript/segments) | فيديو موسيقي بلا كلام |
| punch-ins | كلام + لقطة ثابتة | حركة كاميرا عالية أصلًا |
| B-roll | فيديو > 60s + إيقاع بطيء | قصير/سريع (يخنق الإيقاع) |
| music bed | يوجد كلام + مدة > 30s | صامت/موسيقي أصلًا |
| intro/outro | مدة المستخدم > 45s | قصير (يُذكر السبب) |
| SFX مولّدة | كثافة المرجع > 2/min | فيديو هادئة (تأكيد أولًا) |
| درجات الألوان | دائمًا كبريسِت قابل للضبط | — |

القاعدة الذهبية: **لا حذف لمحتوى المستخدم أبدًا** — التطبيق إضافة/تحويل فقط،
وكل عنصر toggle + preview + سطر "طُبق X لأن فيديوك Y".

## 4. حدود الصدق (غير قابلة للتفاوض)

1. **الأغنية نفسها لا تُكتشف ولا تُوضع** (بصمة سحابية + copyright strike).
   البديل: موسيقى royalty-free بنفس المزاج/السرعة من مكتبتنا.
2. **الموشن المخصص لا يُستنسخ** — مكافئات من مكتبتنا (lower-third، اشتراك،
   تقدم) بنفس الكثافة والتوقيت.
3. **SFX تُولَّد** عبر `sound_forge` الموجود — صفر حقوق، صفر تحميل.
4. **الفكرة/الذوق لا يُنسخان** — فقط المقاس.
5. تنبيه حقوق صغير في الواجهة عند الاستيراد من قناة.

## 5. المراحل

- **P1 (هذه الدفعة):** المحلل المرجعي + DNA موسّع + حفظ/تحميل + اختبارات.
- **P2:** مكتبات (SFX مولّدة، موسيقى RF، قوالب موشن) + Matching Engine.
- **P3:** واجهة (بحث قناة → اختيار → معاينة DNA → تطبيق انتقائي).
- **P4 (اختياري سحابي):** ترانسكريبت + LLM للنصوص فقط (هوك نصي، حالة كابشن).
